# 隐私政策 / Privacy Policy

**最后更新：2026-09-30**

「主机下载加速」（ConsoleDash）不收集、不存储、不上传任何用户个人数据。

## 我们处理的数据

- **不收集**：本应用没有任何账号系统、没有分析统计 SDK、没有广告、没有崩溃上报
- **本地处理**：网络延迟测量（连接测试）在本机完成，结果只显示在你的屏幕上，不离开设备
- **代理流量**：本应用作为局域网代理转发你主动配置的游戏主机下载流量；流量直接在本机与目标服务器之间传输，不经任何第三方服务器

## 权限使用

- **本地网络**：仅用于接收同一 Wi-Fi 下你主动连接的游戏主机请求

## 联系

通过 GitHub 仓库 issue 联系：https://github.com/kkksssmmmm-nuoyier/ns2-dns-accel

# Privacy Policy (English)

**Last updated: 2026-09-30**

ConsoleDash collects, stores, and transmits **no personal data whatsoever**. There are no accounts, no analytics, no ads, and no crash reporting. Latency measurements run entirely on-device and are never sent anywhere. Proxy traffic flows directly between your device and the destination servers — no third-party relay. Local Network permission is used solely to accept connections from game consoles you explicitly configure.

Contact: GitHub issues at https://github.com/kkksssmmmm-nuoyier/ns2-dns-accel
